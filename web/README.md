# Private premium viewer

React/TypeScript static client for the existing Python viewer. It uses the owner's
private premium component closure; there is no Node production server or new
database. See `COMPONENTS.md` for provenance.

## Development checks

From `web/`, run `npm ci --ignore-scripts`, `npm run typecheck`, `npm test`,
`npm run lint`, and `npm run build`. The bundle uses `/ui-v2/` paths and local
fonts. Do not use the Vite development server as a production viewer. Synthetic
browser fixtures must use a separate private Inbox, not the installed database.

Keep `vendor/`, `node_modules/`, `dist/`, generated bundles, screenshots, tokens,
recordings and transcripts out of Git. Public source deliberately cannot build
the premium viewer without the owner's private licensed files.

## Verified release build

Commit only the authored application/configuration/test files. Then run
`scripts/build-viewer.py` from the project with an owner-private absolute
`--output-root` and the existing private `web/vendor` as `--vendor-root`. It freezes
the exact committed `web/` inputs and lockfile, freezes/hashes the licensed input
closure, installs without dependency scripts, and emits a bounded private static
bundle and build provenance. Dirty checkout edits are not deployed.

Pass that generated build to `scripts/package-receiver-release.py
--frontend-build`. The packager verifies the complete committed input inventory,
source revision and every generated byte. The receiver manifest covers JS, CSS
and fonts. Runtime delivery checks hashes again and never exposes provenance or
arbitrary filesystem paths. Follow `OPERATIONS.md` for backup, migration rehearsal,
restart and readback. Rollback selects a previous source/UI release, not an old
database.

## UI and safety

- Recordings, Review, People, Context and Health call the same-origin human APIs.
- Local token bootstrap uses a fragment once, clears it, and stores the token only
  in session storage. Remote access uses the existing Access session.
- Suggested identities are unconfirmed. Sample enrollment defaults off and is a
  separate explicit choice. Conflicts require a successful reread before saving.
- Playback lives outside the views. Filtering and navigation do not replace its
  source. On narrow screens, detail uses a single main pane with Back so global
  audio controls remain reachable. Premium navigation still uses the Sheet.
- Context states describe observations, not speech sources or causes. Stale or
  unknown phone state is not inactivity. Voice diagnostics are an explicit read.
- The new viewer CSP permits only the exact fixed Base UI scrollbar style by
  hash. Inline scripts and other inline styles remain blocked. The legacy CSP
  is unchanged. No CDN, telemetry, service worker or external runtime fetch is used.
- `/legacy/` remains the same human viewer with the same session. No credentials
  are added to the return link.
